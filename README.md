No build system or package installation is required.

### 1. Clone the repository

```bash

```

### 2. Open the project

```bash
cd <repository-name>
```

### 3. Run the website

You can open `index.html` directly in a browser.

## 🤖 Featured Project

### DC Motor Driven Walking Robot

A minimalist walking robot built using:

- DC motor
- Battery
- Chopsticks

The project uses a **crank-rocker linkage mechanism** to convert rotational motor motion into a walking gait. It was designed without a microcontroller, making it a purely mechanical robotics project.

- **Total cost:** < ₹100
- **Mechanism:** Crank-Rocker Linkage
- **Microcontroller:** None
- **Project inspiration:** Theo Jansen's Strandbeest

Project repository:

https://github.com/p24256/Dc--motor-walking-robot
